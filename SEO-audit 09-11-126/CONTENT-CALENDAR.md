## 3. Editorial Standards & E-E-A-T Framework

To protect search rankings from Google core algorithm fluctuations and site reputation policies:

1. **Named Editorial Reviewer:** Every published guide must display a dedicated author/reviewer box: *"Reviewed by Tax Compliance & Accounting Editorial Board"*.
2. **Official Source Citations:** Every state rate claim must link directly to the respective State Department of Revenue (DOR) official `.gov` portal.
3. **Primary Formula Callout:** Every informational post must feature an unmissable syntax block:
   ```
   Pre-Tax Amount = Total Price ÷ (1 + Sales Tax Rate)
   Tax Paid = Total Price - Pre-Tax Amount
   ```
4. **AI Citability Standards:** Use Markdown tables, clean numeric lists, and bold summary headers so LLM web scrapers (ChatGPT, Claude, Perplexity) extract direct citations.
